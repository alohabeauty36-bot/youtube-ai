Đăng nhập dashboard

Chỉ cần khi mở dashboard từ máy khác. Nhập mật khẩu chủ kênh hoặc biên tập viên (đặt ở mục Bảo mật dashboard). Lưu trong trình duyệt này.

Tích hợp

Kênh YouTube (OAuth)

Dùng OAuth 2.0 chính thức (không dùng cookie/mật khẩu). Cần dán client_secret.json ở mục YouTube phía trên trước. Khi cấp quyền, chọn đúng kênh; kênh khác ID kênh đích sẽ bị chặn.

Tự động hoá

Giọng đọc VieNeu

Gợi ý thử “Quang Sơn” rồi so sánh đoạn mẫu 30 giây ở trang Biên tập. Clone giọng chỉ mở khi bạn xác nhận sở hữu/được phép dùng giọng mẫu.
